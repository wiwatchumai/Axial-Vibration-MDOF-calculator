# Multidegree of Freedom: Axial Vibration calculator

Key features of the program includes:
1. Boundary setup - fixed on both left-right ends/ either left or right end fixed
2. Each mass will be connected via spring, you can freely adjust each spring stiffness value.
3. Dampers can be included between each pair of masses where you can freely adjust your damping value.
4. Mass can be freely adjusted

Key presentation
- Time-response plot for displacement/ velocity/ acceleration
- Eigenvalues and Eigenvectors

This program is designated due to the purpose of vibration analysis where the real-world systems usually consists of multielements operating in coupled. Single-Degree of Freedom equations is no longer capable with more complex systems analysis. MDOF usually consists of each vibration signal correspond to its natural frequency. Each vibration time-response at each frequency combined will be presented our calculation.
